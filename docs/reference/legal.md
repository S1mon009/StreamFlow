Do not use StreamFlow to access accounts, resources or content that you are not authorized to access.

Cookie files should only contain authentication information belonging to sessions you are authorized to use.

## Cookie security

Authentication cookies are sensitive.

Never publish:

```text

```

in a public repository.

If authentication cookies are accidentally exposed, invalidate the affected session as soon as possible.
